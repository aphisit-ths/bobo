# คาแฟอีน

แอป menu bar สำหรับ macOS กดทีเดียวแล้วเครื่องจะไม่หลับ จอไม่ดับ จนกว่าจะกดปิด

ไอคอนถ้วยกาแฟบน menu bar — **ถ้วยเต็ม = กำลังกันเครื่องหลับ**, **ถ้วยว่าง = ปิดอยู่**

## ทำไมเครื่องบริษัทก็ใช้ได้

เบื้องหลังคือ `IOPMAssertionCreateWithName` ของ IOKit ซึ่งเป็น API ระดับผู้ใช้ตัวเดียวกับที่
คำสั่ง `caffeinate` ที่ติดมากับ macOS ใช้ แปลว่า

- ไม่ต้องใช้รหัส admin ไม่ต้อง `sudo` ไม่ต้องปิด SIP
- ไม่ได้ไปแก้ค่า Energy Saver หรือ setting ใด ๆ ของเครื่อง แค่บอกระบบว่า "ตอนนี้อย่าเพิ่งหลับ"
- พอปิดแอปหรือแอปถูกฆ่า assertion หายไปเอง ค่าเดิมของเครื่องกลับมาทันที

## ติดตั้ง

ต้องมี macOS 13 ขึ้นไป และ Xcode Command Line Tools (`xcode-select --install`)

    cd caffeine-mac
    ./build.sh --install

จะได้ `/Applications/Caffeine.app` แล้วเปิดให้เลย ถ้าไม่อยากติดตั้งก็รัน `./build.sh` เฉย ๆ
ไฟล์จะอยู่ที่ `dist/Caffeine.app`

แอปเซ็นแบบ ad-hoc (ไม่มี Developer ID) — build เองบนเครื่องตัวเองจึงเปิดได้ปกติ
ไม่ติด Gatekeeper เพราะไม่ได้โหลดมาจากอินเทอร์เน็ต

## วิธีใช้

| ทำอะไร | ได้อะไร |
| --- | --- |
| คลิกซ้ายที่ไอคอน | เปิด / ปิด |
| คลิกขวา (หรือ control-คลิก) | เมนูตั้งค่า |

ในเมนูมี

- **ระยะเวลา** — ไม่จำกัด, 15 นาที, 30 นาที, 1 / 2 / 5 ชั่วโมง ครบเวลาแล้วปิดเอง
  เลือกปุ๊บเริ่มนับใหม่ทันที บรรทัดบนสุดของเมนูบอกว่าเหลืออีกเท่าไหร่
- **กันจอดับด้วย** — เปิดไว้ = จอไม่ดับ, ปิด = ปล่อยให้จอดับได้แต่เครื่องไม่หลับ
  (เหมาะกับตอนรันงานยาว ๆ ทิ้งไว้ ไม่ต้องเปลืองจอ)
- **กันหน้าจอล็อก (โหมดดื้อ)** — ค่าเริ่มต้นปิดไว้ ดูหัวข้อถัดไป
- **เปิดทันทีที่เริ่มแอป** — เปิดแอปแล้วทำงานเลย ไม่ต้องไปกด
- **เปิดแอปอัตโนมัติตอนล็อกอิน** — ลงทะเบียนเป็น login item ผ่าน `SMAppService`
  (ต้องให้แอปอยู่ใน `/Applications` ก่อน)

## โหมดดื้อ

การกันจอดับตามปกติไม่ได้กันการล็อกหน้าจอเสมอไป ถ้าเครื่องถูกตั้งให้ล็อกหลังไม่มีการใช้งาน
X นาที ตัวนับ idle ยังเดินอยู่ดี

"โหมดดื้อ" จะเรียก `IOPMAssertionDeclareUserActivity` ทุก 25 วินาที ซึ่งเป็นการบอกระบบว่า
เพิ่งมีการใช้งานเครื่อง ตัวนับ idle เลยถูกรีเซ็ต — screen saver กับ auto-lock จึงไม่เด้ง
เป็น API สาธารณะ ไม่ต้องขอสิทธิ์ Accessibility และไม่ได้ปลอม event เมาส์/คีย์บอร์ด

สองข้อที่ควรรู้ก่อนเปิด

1. การล็อกหน้าจออัตโนมัติมักเป็นนโยบายความปลอดภัยขององค์กร การปิดมันทิ้งไว้อาจผิดกติกา
   ที่ทำงาน — เป็นการตัดสินใจของมึงเอง ค่าเริ่มต้นเลยปิดไว้
2. ถ้า IT บังคับล็อกผ่าน MDM/configuration profile แบบสั่งล็อกตรง ๆ ไม่ได้ดูค่า idle
   แอปนี้ (หรือแอปอื่นในระดับผู้ใช้) เอาชนะไม่ได้ และแอปนี้ไม่ได้พยายามจะไปยุ่งกับ MDM
   หรือซ่อนตัวจากเครื่องมือของ IT แต่อย่างใด

## สิ่งที่แอปนี้ทำไม่ได้

- ปิดฝา MacBook แล้วให้เครื่องตื่นต่อ — อันนั้นเป็นการหลับที่ระบบบังคับ assertion ห้ามไม่ได้
- กันเครื่องหลับตอนแบตใกล้หมด — macOS จะหลับเพื่อรักษาข้อมูลอยู่ดี

## โครงสร้างไฟล์

    Package.swift                     นิยาม SwiftPM executable
    Sources/Caffeine/main.swift       จุดเริ่มแอป ตั้งเป็น accessory app
    Sources/Caffeine/AppDelegate.swift  ไอคอน menu bar, เมนู, ตัวจับเวลา
    Sources/Caffeine/SleepBlocker.swift IOKit power assertion
    Sources/Caffeine/Preferences.swift  ค่าตั้งใน UserDefaults
    Resources/Info.plist              LSUIElement = แอปไม่มีไอคอนใน Dock
    Resources/th.lproj, en.lproj      ชื่อแอปตามภาษาของเครื่อง
    build.sh                          build + ประกอบ .app + เซ็น ad-hoc

## ตรวจว่ามันทำงานจริงไหม

    pmset -g assertions

ตอนเปิดอยู่จะเห็นบรรทัด `PreventUserIdleDisplaySleep` พร้อมชื่อ "คาแฟอีน"
